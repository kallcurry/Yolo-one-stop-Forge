# 生成 UI 优化效果图（不改项目代码）

## 交付物
`mockups/` 目录下 4 张高保真效果图 PNG（1470×660，与现有截图同尺寸可直接对比）：
1. `mockup_0_data.png` — 数据管理：图片画布为主角（占中 ≥55%）、右侧面板收窄为单组 tab（摘要/审查/标注树/文件）+ 可收起、底部工具栏三分组（导航|显示|文件操作）、任务芯片（POSE · annotations）常驻
2. `mockup_1_train.png` — 训练中心：任务表进度列内嵌迷你进度条 + 状态圆点、详情卡按钮固定底栏不重叠、顶部全局任务徽章、运行中悬浮胶囊
3. `mockup_3_eval.png` — 评估中心：空态优先（隐藏全 0 统计卡，三步引导 + 大按钮）、入口收敛（按钮行只留刷新，行操作进右键/详情卡）
4. `mockup_4_global.png` — 全局框架：顶栏六模块（含推理中心一级入口）+ 任务芯片切换弹层 + 消息中心铃铛，展示任务切换的联动反馈（全站徽章变色示意）

## 实现方式
- 在 mockups/ 下写静态 HTML（内联 CSS，复刻现有深色科技风视觉语言：#0A1628 底、青色 #36B7FF/绿 #57E397 主色、面板发光边、网格底纹），内容用截图里的真实数据（ShengSong_Datasets、2026-08-27-pose 等）保证代入感
- 用浏览器无头截图输出 PNG（browser-use 或本地 chromium）
- 只新建 mockups/ 目录，不触碰 app/、resources/ 等任何现有代码
